SmartRecSys — AI-Powered Course Recommendation System

Project Overview

SmartRecSys is a web-based academic course recommendation platform developed as a final-year major project. It accepts a student's academic profile as input and returns a ranked list of relevant courses, each accompanied by a match score and a plain-language explanation of why it was recommended.

The system is composed of a plain HTML/CSS/JS frontend and a Python-based backend that exposes a REST API. The recommendation logic is implemented as a machine learning model trained on a curated course dataset.

Objectives

  • Reduce the time students spend manually browsing course catalogues.
  • Provide data-driven, personalised course suggestions based on academic profile.
  • Make the recommendation reasoning transparent through per-course explanations.
  • Demonstrate a complete ML-powered web application as a major project deliverable.
  • Produce a maintainable, documented codebase that can be extended in future work.

Features

Profile-based input

Collects name, department, degree, semester, completed courses, preferred domains, difficulty level, and career goal.

ML-powered scoring

A trained model computes a relevance score (0.0–1.0) for each course relative to the submitted profile.

Ranked results

Courses are returned in descending score order with domain and difficulty tags.

Explained recommendations

Each card includes a short reason explaining the match.

Filter & search

Results can be filtered by domain and difficulty level without re-querying the backend.

Access guard

The dashboard is inaccessible without a valid profile submission — direct URL access redirects to the welcome page.

  • The browser collects the student profile via home.html and passes it as URL parameters to dashboard.html.
  • The dashboard JS reads those parameters and sends a POST /recommend request to the backend.
  • The backend validates the input, runs it through the ML model, and returns a JSON array of scored courses.
  • The frontend renders the results using the buildCard() function without any page reload.

Machine Learning Model

The recommendation model is implemented in recommender.py (and optionally dl_recommender_gpu.py for a deep-learning variant). It takes a feature vector derived from the student profile and computes a cosine-similarity or classification-based relevance score for each course in the catalogue.

  • Input features: domain preferences (one-hot), difficulty level (ordinal), semester (ordinal), completed course embeddings.
  • Output: a score in [0, 1] per course, where 1.0 indicates a perfect profile–course match.
  • Training: supervised on historical enrolment and rating data from the course dataset.
  • Inference: runs at request time; typical latency is under 200 ms on CPU.

Dataset Information

The course catalogue dataset contains records for courses across six primary domains: Programming, Web Development, Data Science, Machine Learning, Cybersecurity, and Cloud Computing. Each record includes:

  • Course title and short description
  • Domain and sub-domain tags
  • Difficulty level (Beginner / Intermediate / Advanced)
  • Estimated duration in weeks
  • Skills covered (comma-separated)
  • Prerequisite course identifiers (optional)

The dataset was curated and cleaned by the research team member. It does not contain any personally identifiable student information.

Recommendation Workflow

  1. Student visits welcome.html and clicks Get Started.
  2. Student fills in the academic profile form on home.html and submits.
  3. Form data is validated client-side; on success it is encoded as URL query parameters.
  4. Browser navigates to dashboard.html?name=...&domains=...&level=....
  5. Dashboard JS reads the parameters, verifies they are present (guard), then sends POST /recommend.
  6. Backend returns a JSON array: [{ title, domain, difficulty, score, duration, description, skills, reason }, ...].
  7. Frontend renders the featured top-3 row and the full results grid using buildCard().
  8. Student can filter results by domain or difficulty without a new API call.

Installation Guide

Frontend (no build step required)

# Clone the repository
git clone <repo-url>
cd "Major Project/frontend"

# Open in browser directly — no server needed for the frontend alone
open welcome.html   # macOS
start welcome.html  # Windows

Backend

# From the project root
cd backend   # or wherever recommender.py lives

# Create a virtual environment
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the API server
python app.py   # or: uvicorn app:app --reload  (FastAPI)

The API will be available at http://localhost:5000 by default. Update the URL in app.js if you use a different port.

User Guide

  1. Open welcome.html in your browser.
  2. Click Get Started to go to the profile form.
  3. Fill in all required fields (marked with *).
  4. Select at least one domain of interest and a difficulty level.
  5. Click Get Recommendations.
  6. Review the top-3 featured matches at the top of the results page.
  7. Use the domain and difficulty filters to narrow down the full list.
  8. Read the Why recommended section on each card for context.
  9. Click ← Back or navigate to Home to adjust your profile and re-run.

Future Scope
